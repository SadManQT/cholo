# Geographic boundary data

`bangladesh-boundary.json` is a simplified GeoJSON snapshot of OpenStreetMap
relation `184640` (Bangladesh), retrieved through the Nominatim lookup API with
`polygon_threshold=0.002` on 2026-08-14.

Source: https://www.openstreetmap.org/relation/184640

OpenStreetMap data is available under the Open Database Licence (ODbL):
https://www.openstreetmap.org/copyright

The server uses this snapshot only to verify that every point and segment of a
proposed driving route remains inside Bangladesh. It is not a source of street
or address data.
