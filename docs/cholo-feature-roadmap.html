🤝 Working through this with a partner

One drives, one navigates, swap every feature. Whoever's "driving" pastes the BUILD prompt into their agent session. The navigator opens a second session in the same repo and pastes the UNDERSTAND prompt once the build is done — so both of you can explain every line before it's committed, not just the person who typed it.

Some steps can run in parallel — they're marked green below with who can start what. Everything else is strictly sequential: don't start step 12 before step 11 is merged.

Checkboxes are shared: checking one off commits the change to docs/roadmap-progress.json in this repo via the GitHub API, so it shows up for both of you within seconds — no need for GitHub Issues just to track this. Anyone can view the shared progress; checking things off needs a one-time GitHub token, set up with the button above (stored only in your own browser, never shipped in this file).
